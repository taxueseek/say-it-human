# 四类场景标点规则详解

---

## 场景A：中文散文（公众号/博客/随笔）

### 全角标点强制
- 逗号：`，`
- 句号：`。`
- 问号：`？`
- 感叹号：`！`
- 冒号：`：`
- 分号：`；`
- 括号：`（）`

### 引号规范
- 直角引号 `「」` 用于概念和对话
- 不用于强调（想强调用加粗）
- 引号内末尾标点：`「你好。」` 不是 `「你好」。`

### 破折号
- 禁用（用逗号/句号/括号替代）
- em-dash是AI味强指纹

### 省略号
- 六个点 → `……`
- 不连续使用

### 顿号
- 分隔中文并列短词
- 两项列表可用可不用
- 三项及以上建议用

### 感叹号
- 全文≤3处
- 禁止连用 `！！！`

## 场景B：技术文档（API/手册/Runbook）

### 中西文间空格
- `使用 React 构建`（中文+英文）
- `调用 API 接口`（中文+缩写）
- `版本 v1.2.3`（中文+数字）

### 代码围栏保护
- ```` ``` ```` 内标点100%不动
- 不区分全角半角

### 行内代码保护
- `` `...` `` 内标点不动

### URL保护
- `http://...` `https://...` 内标点不动

### 数字保护
- `1,000` 千分位逗号保留
- `3.14` 小数点保留
- `12:30` 时间冒号保留

### 标题层级
- `#` 一级（文章标题）
- `##` 二级（章节）
- `###` 三级（小节）
- 不超过三级

### 列表格式
- 有序列表：有顺序时使用
- 无序列表：平行项使用
- 列表项末尾标点统一

## 场景C：中英混排（双语发布/国际化）

### 排版规则
- 中文块与英文块之间加空格
- 中文括号内嵌英文：括号全角，内部英文标点用半角
- 英文块内嵌中文：英文标点用半角，内部中文标点用全角

### 术语一致性
- 首次出现：保留英文+中文注解
- 后续出现：统一用中文
- 行业通用缩写（SFT/RL/MoE）全程保留

### 常见可替换词
| 英文 | 推荐中文 |
|------|----------|
| context | 上下文 |
| state | 状态 |
| cache | 缓存 |
| claim | 断言 |
| runtime | 运行时 |
| contract | 契约 |

---

## 场景D：社交媒体（小红书/即刻/推特）

### 适度灵活
- 允许适度使用emoji（每段≤2个）
- 允许适度使用感叹号（表达情绪）
- 允许使用---分隔线

### 底线
- 中文不能用半角标点
- 中西文间仍需空格
- 不能连续3个以上感叹号

### 平台特殊规则
| 平台 | 特殊规则 |
|------|---------|
| 小红书 | 标题≤20字，关键词前置 |
| 公众号 | 标题15-30字，引发好奇 |
| 知乎 | 标题疑问句，长尾关键词 |
| 抖音 | 标题吸引眼球，有冲突感 |
| 即刻 | 标题短句+话题标签 |
