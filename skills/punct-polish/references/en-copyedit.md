# 英文校对规则（Copyedit）

基于write-en.md + 通用英文编辑规范。

---

## 字符级规则

| 检查项 | 规则 | 示例 |
|--------|------|------|
| 逗号后空格 | 逗号后必须有空格 | `a,b` → `a, b` |
| 句号后空格 | 句号后必须有空格 | `end.Start` → `end. Start` |
| 引号方向 | 弯引号 `"` `'` | 非代码场景 |
| 破折号 | `---` → `—` / `--` → `–` | 英文场景 |
| 省略号 | `...` → `…` | 自动 |
| 首字母大写 | 句首单词大写 | `hello.` → `Hello.` |
| 连续空格 | 多个空格合并为一个 | `a  b` → `a b` |

## 句式避免

| 结构 | NO | OK |
|------|----|----|
| 否定并列 | "It's not X. It's Y." | 直接说结论 |
| 空泛形容 | "The reasons are structural" | 具体说明原因 |
| 强调副词 | "quietly orchestrating" | 直接说做了什么 |
| 形式主语 | "It is important to..." | "You should..." |

---

## 标点规范

| 标点 | 用法 |
|------|------|
| 逗号 | 并列连词前、从句后、列表分隔 |
| 句号 | 陈述句末尾 |
| 分号 | 相关独立分句连接 |
| 冒号 | 解释、列举、引用 |
| 破折号 | 解释说明（同中文规则） |
| 引号 | 直接引用、反讽、术语首次出现 |
