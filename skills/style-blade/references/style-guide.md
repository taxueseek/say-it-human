# 风格对照表

| 风格 | 核心特征 | 适用场景 | 禁忌 |
|------|---------|---------|------|
| 棱角模式 | 有态度、不圆滑、会刺到人 | 观点输出、社会评论、品牌态度 | 两面讨好、总结升华 |
| 锐利模式 | 短狠准、关键句置后 | 社交媒体、快速传播、记忆点 | 解释铺垫、过渡句 |
| 密度压缩 | 外科手术式删减 | 精简摘要、标题提炼、快速阅读 | 保留废话、重复信息 |

---

## 棱角感四法

| 手法 | 说明 | 示例 |
|------|------|------|
| 错位 | 把不该放一起的东西放一起 | 公司的成功是老板的，项目的成功是团队的，只有简历和银行卡余额是你的 |
| 反转 | 先说共识，再刺破 | 天天发推特讲赚钱的人大部分不赚钱 |
| 留白 | 不说满，让读者自己填 | 其他都是噪声 |
| 具体 | 用数字和场景代替形容词 | 凌晨两点的写字楼，三分之一的灯还亮着 |

---

## 密度压缩判断体系

1. **第一判断**：删掉之后，读者损失了任何信息吗？不损失 → 必须删
2. **空判断优先删**：说了「重要」但找不到对应的代价或结果 → 最重该删
3. **可指性优先留**：能用手指出来的，留着
4. **词长可疑**：两字以上的形容词和副词组合几乎都可以删

## 高频替换表

| 不自然 | 自然 |
|--------|------|
| 非常/极其 | 很 |
| 值得注意的是 | 直接说结论 |
| 综上所述 | 直接收尾 |
| 例如 | 比如 |
| 购买/使用 | 买/用 |
| 很多同学 | 很多人/不少人 |
| 这几个事 | 这几件事 |
| 至关重要 | 重要 或 删 |
| 不可或缺 | 少不了 或 删 |
| 深度赋能 | 直接用 或 删 |

## 三问自检

写完后逐一检验，不过关则重写：

1. 读第一句能猜到最后一句吗？→ 能，重写
2. 把作者名字遮掉，像任何人都能写的吗？→ 是，重写
3. 有没有一句话让人想截图？→ 没有，重写
