# 风格刃（Style Blade）

> 不是让文字「更好看」，是让文字「有态度、有个性、有记忆点」。

---

## 三种模式

### 模式A：棱角模式（Attitude）

**来源**：棱角文案

**铁律**：
- 必须有棱角：选一个方向说到底，不两面讨好
- 不可预测：读第一句猜不到最后一句
- 说完就停：不总结、不升华、不"你觉得呢"

**写法**：
- 短句为主，一句一行
- 用类比代替论证，用错位制造张力
- 同一结构重复两次，第三次翻转
- 删到不能再删，删完再删一句

**棱角感四法**：
| 手法 | 说明 | 示例 |
|------|------|------|
| 错位 | 把不该放一起的东西放一起 | 公司的成功是老板的，项目的成功是团队的，只有简历和银行卡余额是你的 |
| 反转 | 先说共识，再刺破 | 天天发推特讲赚钱的人大部分不赚钱 |
| 留白 | 不说满，让读者自己填 | 其他都是噪声 |
| 具体 | 用数字和场景代替形容词 | 凌晨两点的写字楼，三分之一的灯还亮着 |

**自检**：
- [ ] 有"一方面...另一方面"？→ 删掉，选一个
- [ ] 读者能猜到结尾？→ 重写，制造意外
- [ ] 最后一句是呼吁/提问/总结？→ 删掉，直接停
- [ ] 有超过15字的长句？→ 打断
- [ ] 用了「重要」「关键」「本质上」？→ 删掉，直接说事

---

### 模式B：锐利模式（Sharp Cut）

**来源**：sharp-copywriter + sharp-edit

**铁律**：
- 每句话删到不能再删
- 关键句放最后，不放在开头
- 不解释自己为什么这么说
- 禁止总结段，说完就停

**写法**：
- 短句为主，长句只在需要堆信息密度时出现
- 段落之间要有跳跃感，不要过渡句
- 像说话，不像写作

**密度压缩四法**：
| 手法 | 说明 | 示例 |
|------|------|------|
| 空判断清除 | 说了"重要"但找不到代价或结果 | "这一点至关重要" → 删掉 |
| 可指性优先 | 能用手指出来的留着 | "他回我消息从来不超过三分钟" 留着 |
| 词长可疑 | 两字以上形容词/副词组合几乎可删 | "非常重要" → "重要" |
| 模糊表述逼表态 | "在一定程度上" → 明确表态或直接删 | "比较重要" → "重要" 或 删 |

**自检**：
- [ ] 删掉之后读者损失了任何信息吗？不损失 → 必须删
- [ ] 还有空判断没被清掉？有 → 继续
- [ ] 还有模糊词没被处理？有 → 继续

---

### 模式C：密度压缩（Density Compress）

**来源**：sharp-edit

**唯一任务**：每个字都要能承受重量，承受不住的删掉。

**判断体系**：
1. **第一判断**：删掉之后，读者损失了任何信息吗？不损失 → 必须删
2. **空判断优先删**：说了「重要」但找不到对应的代价或结果 → 最重该删
3. **可指性优先留**：能用手指出来的，留着
4. **词长可疑**：两字以上的形容词和副词组合几乎都可以删

**四项操作**：
| 操作 | 说明 |
|------|------|
| 删冗余词 | 每个形容词、副词、程度词都要过审 |
| 删无价值句 | 过渡句、客套句、重复义句 |
| 替换模糊表述 | "在一定程度上" → 具体或删 |
| 标出模棱两可词 | 【也许】【可能】→ 要求二选一 |

## 统一自检清单（三问）

写完后逐一检验，不过关则重写：

1. **读第一句能猜到最后一句吗？** → 能，重写
2. **把作者名字遮掉，像任何人都能写的吗？** → 是，重写
3. **有没有一句话让人想截图？** → 没有，重写

---

## 与其他技能的协作

```
humanize-ai（去AI味） → style-blade（风格注入，可选） → editor-revisor（删废话）
```

**典型用法**：
- "来一段有态度的" → 棱角模式
- "写得犀利一点" → 锐利模式
- "压缩到最狠" → 密度压缩模式
- "先锐利再压缩" → 锐利模式 + 密度压缩依次执行

---

## 输出格式

直接输出风格化后的文本，不解释改了什么。

---

## DO NOT

- 为了"更口语"硬塞俚语、感叹词
- 把有生命力的文章改成"正确"的文章
- 改动作者的立场或程度
- 替作者补他没有的经历或细节
- 在棱角/锐利模式下使用"首先/其次/最后"
